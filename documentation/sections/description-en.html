Climatology: Description back to ToC

Ontology for representing climatological data. Concrete examples of use of the Environmental Sensors Ontology for climatological magnitudes. The example included in the repository illustrates its use: a weather station (edintmed:SensorPlatform) with a wind speed sensor (edintmed:EnvironmentalSensor) hosted by it through sosa:hostedBy, and an observation (edintmed:EnvironmentalObservation) whose result is a qudt:QuantityValue expressed in unit:M-PER-SEC. Classifications come from the SKOS schemes of sensor types, environmental properties and features of interest.

Figure 1 shows an example of use of the Environmental Sensors Ontology for climatological magnitudes.

There is a weather station with the identifier "102" that is an instance of edintmed:SensorPlatform. This station features an edintmed:environmentalSensor with the identifier "MET_102_81"—a wind speed sensor that is sosa:hostedBy the station. Its type within the kos:SensorTypes SKOS taxonomy is "ClimaticSensor". Note that the environmental sensor ontology defines the station as a subclass of geosparql:Feature, allowing for the representation of its geospatial data.

The sensor lists the company "Vaisala" as its schema:manufacturer. The figure depicts a wind speed observation, which is an instance of edintmed:EnvironmentalObservation. Specifically, the sosa:observedProperty property links the observation to an edintmed:EnvironmentalProperty—in this case, "WindSpeed," a value belonging to the kos:EnvironmentalProperty SKOS taxonomy.

The observation has a sosa:hasFeatureOfInterest—the measured entity, in this case "Wind," which belongs to the kos:FeaturesOfInterest SKOS taxonomy. The observation also has a sosa:hasResult linking to an instance of qudt:QuantityValue; this instance has a qudt:hasNumericValue of "2.6" and a unit of "unit:M-PER-SEC" (an instance of unit:Unit), representing wind speed in meters per second.
