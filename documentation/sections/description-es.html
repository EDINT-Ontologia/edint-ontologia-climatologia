Climatología: Descripción volver a índice

Ontología para la representación de datos climatológicos. Ejemplos de uso concretos de la ontología de Sensores Medioambientales para magnitudes climatológicas. El ejemplo incluido en el repositorio ilustra su utilización: una estación meteorológica (edintmed:SensorPlatform) con un sensor de velocidad del viento (edintmed:EnvironmentalSensor) alojado en ella mediante sosa:hostedBy, y una observación (edintmed:EnvironmentalObservation) cuyo resultado es un qudt:QuantityValue expresado en unit:M-PER-SEC. Las clasificaciones se toman de los esquemas SKOS de tipos de sensor, propiedades medioambientales y características de interés.
